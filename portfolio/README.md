# Syeda Sobia Fatima — Portfolio

A responsive portfolio built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript (ES6+).

## Structure

- `index.html` — semantic page structure and Bootstrap layout utilities
- `css/style.css` — custom pastel green + beige visual theme
- `js/script.js` — navbar, theme toggle, scroll spy, project filtering and form validation
- `assets/hero-banner.jpg` — local hero/banner image

## Design

- Pastel green: `#ccd5b5`
- Light green: `#e6ecd9`
- Warm beige: `#f4f0e6`
- Light cream: `#faf8f1`
- Black/near-black text: `#171b18`

The previous desktop sidebar has been replaced with one responsive top header. The profile/SSF image block was removed. The flower image is now a full-width, short responsive banner with a soft beige fade so it visually blends into the page.

## Note about Bootstrap

The page uses Bootstrap 5.3.3 from jsDelivr for the responsive navbar, grid and form utilities. No external font imports are used.
